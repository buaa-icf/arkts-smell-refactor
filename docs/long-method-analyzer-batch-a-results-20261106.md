## I6：评审输出协议失败

该条在 293.922 秒结束，设备 LoginPageTest 3/3、其他门禁均通过。`review-agent.log` 的最终文本开头为：

```text
{“verdict”:“通过”,“summary”:"长方法异味已消除：...
```

JSON 字段/值的部分引号是弯引号，verdict 又是中文“通过”，不符合约定的 `PASS | FAIL | UNCERTAIN`。因此没有产生 `review.json`，流水线把评审阶段置为 BLOCKED；日志中的自然语言正面结论不能代替结构化评审通过。

只读复现调用 `finalReviewText()`、`parseReview()`、`formatRetryPrompt()`：解析和格式重试入口均返回 null。当前仅格式重试要求原文以 ASCII `{"verdict":"PASS|FAIL|UNCERTAIN"` 开头，所以这次没有触发。不是 1200 秒总超时、设备崩溃、编译失败或真实 UNCERTAIN 结论。

后续若优化此处，应处理评审输出协议与受限重试，保留完整原结论及证据，并严格验证 schema；不直接把“通过”字符串映射为验收 PASS，也不回写这次历史结果。本轮只分析，不修改此机制。
