ArkTS 对话式重构 Skill：Windows 安装说明

安装和运行使用批处理与包内 JavaScript，不需要 TypeScript、npm 或开发仓库。

一、安装

1. 下载发布者提供的 arkts-smell-refactor.zip，并完整解压。
   找到同时包含 install.bat、SKILL.md、scripts 和 runtime 的目录。
   不要在压缩包预览中运行，也不要只复制 install.bat 或 SKILL.md。

2. 本机需要 Node.js 20.19 或更高版本，并能从 PATH 找到 node。
   若 DevEco Code 要求更高版本，以其要求为准。
   没有 Node.js 或版本太低时，安装会提示原因并结束，不会自动下载安装。
   可从 https://nodejs.org/en/download 选择受支持的 LTS Windows 安装包，
   安装后重新打开终端，执行 node --version 确认版本，再重新运行 install.bat。
   已安装却找不到时，将包含 node.exe 的目录加入用户 PATH 后重新打开窗口。

3. 双击解压目录中的 install.bat，查看窗口显示的安装结果。
   默认安装到当前用户的：
     %USERPROFILE%\.config\deveco\skills\arkts-smell-refactor
   如已设置绝对路径 XDG_CONFIG_HOME，则使用其下的 deveco\skills 目录。
   已有同名安装时，入口会先备份再升级，并保留原有工具设置。
   安装成功时会显示实际安装位置；升级时同时显示备份位置。

4. 退出并重启 DevEco Code，在目标 HarmonyOS 业务工程中开始聊天。
   在 /skills 中确认 arkts-smell-refactor，然后说：
     使用 arkts-smell-refactor，先检查环境，再检测
     entry/src/main/ets/pages/Index.ets，展示检测结果和重构建议。
   请将示例文件换成工程中的实际文件。

Skill 安装一次即可用于不同工程，不绑定某个业务项目。
安装完成只说明文件已就绪；首次对话仍会检查 SDK、构建工具、DevEco 和审查模型配置。
缺项时会列出具体原因和配置方法，然后结束本次执行。
补齐依赖后重新发起请求，不会通过修改业务代码或跳过验收来绕过缺项。

二、可选：从命令行安装或配置工具

在完整解压目录打开终端：

  .\install.bat --no-pause
  .\install.bat --no-pause --studio "D:\Tools\DevEco Studio"
  .\install.bat --no-pause --config "D:\settings\arkts-tools.json"

--no-pause 放在首个参数，仅关闭窗口结束前的按键等待，适合命令行和自动调用。
--studio 指定 DevEco Studio 的绝对安装路径。
--config 读取 JSON 工具设置；仅复制 studio、deveco、hvigor、ohpm、linter、
linterMode 和 timeoutMs。本次提供的工具设置覆盖已有值，原配置文件不改写。
历史配置中的 projectRoot、backend、bridgePath、runs、node 不会形成工程绑定。

三、预检与排查

需要手动指定工程时，在终端执行（将路径替换为实际安装目录及工程目录）：

  node "<已安装Skill目录>\scripts\run.mjs" doctor --project "D:\harmonyos\MyApplication"

默认从当前工作目录向上寻找最近的 HarmonyOS 工程。
看到 BLOCKED 时，按 missing 列表中的 action 补齐环境；不要把安装成功当作验收通过。
如果重启后没有加载新版，可用 deveco debug skill 查看实际加载位置，检查是否存在
项目级同名 Skill。完整命令说明在 references\cli.md。

DevEco Code、SDK、Node.js、签名及设备环境由本机提供。
